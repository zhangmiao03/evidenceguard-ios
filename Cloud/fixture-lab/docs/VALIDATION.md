- pytest 留有两条第三方测试客户端弃用提醒，无测试失败；不影响当前运行，后续依赖维护时处理。

端到端逐项结果、时间与证据 ID 见 [smoke-results.json](smoke-results.json)。这里的秒数是本机从切换场景到满足检查条件的单次等待时间，不是模型推理延迟、性能基准或设备服务承诺。

## 运行中发现并修正

1. 本机 FFmpeg 的 RTSP demuxer 不支持 `rw_timeout`，改用其实际支持的 `timeout`，加入明确的探测参数。
2. FFmpeg 在管道上等待时仅发终止信号可能导致重连阻塞，改为关闭输入、排空输出、有界等待及必要时强制回收；增加回归测试，真实双路恢复检查通过。
3. “无法确认”和证据冲突事件最初没有附图，已改为保留相关画面及其原始时间，支持回查。
4. 手机布局优先呈现守护结论与复核入口，模拟控制放在后面。
