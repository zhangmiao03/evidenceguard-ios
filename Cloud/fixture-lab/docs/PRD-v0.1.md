# 首轮 PRD：双摄守护验证

用户目标：对一个区域中的箱子持续观察，能区分在区域内、已离区、目前无法判断；每个结果能回查画面来源和时间。

## 主流程

进入工作台 → 查看预设的“看住门口的箱子” → 分别圈选两个视角对应的守护区域 → 确认规则版本 → 等待有效观察 → 查看结论/告警 → 查看证据 → 请求重新观察。

本轮预设目标为带 #17 标记的箱子，目标名称是任务描述。下一轮才加入任意目标选择、自然语言创建和多任务管理。

## 规则

| 结果 | 进入条件 | 告警行为 |
|---|---|---|
| 已确认 | 同一可用视角连续两次独立观察为区内；间隔不超过 3 秒，画面在 6 秒时效内 | 已有告警可由新证据解决 |
| 需要处理 | 同一可用视角连续两次独立观察为区外，满足同等时效与连续要求 | 新建一次异常 episode，持续异常去重 |
| 无法确认 | 遮挡、缺少标记、边界、断流过期、证据冲突或尚未满足确认次数 | 保留已有未解决告警 |

上述数字是**原型实验参数**，用于快速复现，不是已校准的产品准确率或真机性能承诺。位置使用标记中心代替物体完整轮廓，此处不判断物理尺寸。

第二视角只有在绑定目标、区域和时间条件成立时才可补证。两个有效视角发生冲突时保持未知；第二视角落后于当前主视角超过 2 秒时不用于当前补证。

“重新观察”只标记已知晓并请求新图；不能直接改成已确认。暂停保留历史结论与告警，恢复后要求新图。服务重启亦如此。

## 验收与范围

验收依赖真实运行的 RTSP 链路、后端 API 和可读取的原始画面，不以页面换文案代替。

必测：区内、区外、单视角遮挡、双遮挡、相似标记、冲突、旧图、断流与重连、事件片段时效、按需抓拍、不支持命令、复核、暂停恢复、规则版本、持久化。

首轮不含：官方相机兼容认证、真实无标记目标的模型评测、自然语言 Agent、云服务上线、原生移动端 SDK、跨镜自动目标关联。它们分别列为下一阶段工程事项，不由本轮测试结果推断完成。
